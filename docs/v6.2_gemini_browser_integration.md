# Milestone V6.2 — Gemini Browser Integration

## Overview

Milestone V6.2 extends the Personal AI Memory Layer browser extension to directly support **Google Gemini** (`https://gemini.google.com/`).

It allows users working inside Google Gemini to:
1. Search active Gemini conversation messages (DOM visible messages vs backend history).
2. Perform global searches across all stored AI history (including ChatGPT and Gemini memories).
3. Insert recovered context blocks directly into the Gemini prompt composer with a single click.
4. Execute cross-AI memory handoff (retrieving ChatGPT memories inside Gemini, and Gemini memories inside ChatGPT).

---

## Architecture & Provider Adapter

The Gemini Browser Integration operates using the provider abstraction defined in V6.0/V6.1:

```text
                    GEMINI (https://gemini.google.com/)
                                    │
                                    ▼
                          🧠 Memory Layer Button
                                    │
                                    ▼
                           Memory Layer Overlay
                                    │
                  ┌─────────────────┴─────────────────┐
                  ▼                                   ▼
        Search This Conversation            Search All AI Memory
                  │                                   │
                  └─────────────────┬─────────────────┘
                                    ▼
                         Local REST API Server
                        (http://127.0.0.1:8000)
                                    │
                                    ▼
                         SQLite Database & FTS5
```

### Provider Implementation (`extension/providers/gemini.js`)

- **Page Match**: Matches `window.location.hostname.includes("gemini.google.com")`.
- **Title Extraction**:
  - Strips `- Gemini` suffix from `document.title`.
  - Searches active chat sidebar and header selectors (`div[aria-selected="true"] .conversation-title`, `a[aria-current="page"]`, `header h1`, etc.).
- **Composer Selection Strategy**:
  - Uses dynamic fallback selector array prioritizing Quill editors, `<rich-textarea>`, `[contenteditable="true"]`, and `<textarea>` elements.
  - Verifies element visibility with `_isElementVisible()`.
- **DOM Message Parser**:
  - Parses visible user queries (`user-query`, `.user-query-container`, `div[data-test-id="user-query"]`) and model response blocks (`model-response`, `.response-container-content`, `div[data-test-id="model-response"]`).
- **Prompt Insertion**:
  - Focuses composer, inserts context using `PromptInjector.insertTextIntoComposer()`.
  - Dispatches native `input` and `change` events.
  - **CRITICAL SAFETY RULE**: Strictly performs `INSERT ONLY`. Never clicks Send or submits prompts automatically.

## V6.2.x — Opt-In Auto-Sync Implementation

Milestone V6.2.x introduces an **Opt-In Auto-Sync Engine** allowing users to automatically persist rendered web conversations from ChatGPT and Gemini directly into their local Memory Layer database (`data/memory.db`).

### Privacy & Auto-Sync Control

- **Opt-In Gate**: Setting `"Auto-sync web chats to Memory Layer"` added to the extension popup interface.
- **Default State**: Strictly **OFF** (`false`). Conversations are **NEVER** automatically saved unless the user explicitly turns Auto-sync ON.
- **Persisted State**: Saved in `chrome.storage.local`.

### Architecture

```text
Rendered ChatGPT / Gemini Webpage
               │
               ▼
   currentAdapter.readVisibleMessages()
               │
               ▼
   ConversationSyncEngine (extension/core/sync_engine.js)
   - Checks auto_sync_enabled == true
   - Waits for token streaming to finish
   - Debounces sync (1.5s)
   - Computes fingerprint hash (skips duplicate requests)
               │
               ▼
   POST /api/v1/conversations/sync (app/api/server.py)
               │
               ▼
   ConversationRepository.save_conversation()
               │
               ▼
   SQLite data/memory.db + FTS5 + SentenceTransformer Embeddings
```

### Local REST Sync API Endpoint

`POST /api/v1/conversations/sync`

- **Payload Schema**:
  ```json
  {
    "provider": "ChatGPT" | "Gemini",
    "conversation_id": "...",
    "title": "...",
    "messages": [
      { "role": "user", "content": "...", "index": 0 },
      { "role": "assistant", "content": "...", "index": 1 }
    ]
  }
  ```
- **Validation**:
  - Validates provider is supported (`ChatGPT`, `Gemini`, `Claude`).
  - Requires non-empty `conversation_id`, `title`, and `messages` array.
- **Idempotency & Duplicate Prevention**:
  - Reuses `ConversationRepository.save_conversation()`.
  - Maps message IDs as `f"{conversation_id}_msg_{index}"`.
  - SQLite `INSERT OR REPLACE` upserts existing message rows seamlessly without duplicating data.
  - Automatically updates FTS5 search index and 384-dim `all-MiniLM-L6-v2` vector embeddings.
